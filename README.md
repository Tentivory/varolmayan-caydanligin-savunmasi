# Varolmayan Çaydanlığın Savunması

Bu depo, Güneş'in yörüngesinde durduğu iddia edilen ama kimsenin görmediği çaydanlığın **uluslararası, evrensel ve biraz da küstah** resmi savunmasıdır.

Bilim insanları "kanıt yok" der. Biz "kanıt istemiyoruz, çay istiyoruz" deriz.

## Bu proje ne işe yarar?

- Hiçbir şeye.
- Varoluşsal krizlerinize resmi bir gerekçe üretir.
- Çaydanlığın yokluğunu, yokluğun en güçlü kanıtı olarak kabul eder.
- Terminalinizi bir mahkeme salonuna çevirir.

## Kurulum

```bash
python3 savunma.py
```

Başka bir şey gerekmez. Gerekseydi çaydanlık zaten gelirdi.

## Kullanım

Program size çaydanlığı görüp görmediğinizi sorar.
Cevabınız ne olursa olsun savunma kazanır.
Çünkü yokluk, en iyi avukattır.

## Felsefi dayanak

1. Görülmeyen çaydanlık, görülen çaydanlıktan daha gerçektir.
2. Demlik ısınmasa bile fikir kaynar.
3. Kanıt yükü, çay demeyenlerdedir.
4. Eğer çaydanlık yoksa, sen kimsin?

## Uyarı

Bu yazılım çay üretmez. Sadece çaydanlığın yokluğunu üretir.
